# 📌 Real-Time Facial Emotion Detection

A web-based application that detects human emotions in real-time using webcam input and deep learning. The system captures live video, detects faces, and predicts emotions instantly.

## 🚀 Features

- 🎥 Live webcam face detection  
- 😊 Real-time emotion recognition  
- ⚡ Fast and responsive UI  
- 🧠 Deep learning-based prediction  
- 🌐 Web-based application (Flask + JS)  
- 📊 Detects 7 emotions:
  - Angry  
  - Disgust  
  - Fear  
  - Happy  
  - Sad  
  - Surprise  
  - Neutral  

---

## 🧠 How It Works

1. Webcam captures live video  
2. Face is detected using OpenCV  
3. Face is preprocessed (48×48 grayscale)  
4. Deep learning model predicts emotion  
5. Result is displayed in real time  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Flask (Python)  
- **Computer Vision:** OpenCV  
- **Deep Learning:** TensorFlow, Keras  
- **Model:** CNN (`emotion_detection.hdf5`)  
- **Dataset:** FER2013
